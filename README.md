# プロンプトラボ

PCでテーマごとにAIへの指示を練習するWebアプリです。キャッチコピーを置かず、練習操作とキラーワードを中心にしています。

- Webサイト / スライド / 議事録 / 業務改善 / 文章・SNS / 医療・専門職の6テーマ・18題
- 42個のキラーワードと独自の意味・例文。自分のワードを100件まで追加・編集可能
- ワードをお題に追加し、入力中の使用状況を確認
- 目的 / 対象・背景 / 出力形式 / 制約・こだわり / 検証の5軸100点のルール採点
- 依頼者の相談→自分の提案→追加質問を練習する教材ロールプレイ
- Cloudflare Workers AIの任意コーチ相談（送信前に内容を説明）
- 音声入力・キャラクターの読み上げ、初回の全画面スケルトン、操作アニメーション
- お題別下書き・お気に入り・履歴の端末内保存、JSON書き出し

## ローカル実行

Node.js 22以上が必要です。フロントエンドとローカルテストに追加パッケージは不要です。

```sh
npm run dev
```

[ローカル画面](http://127.0.0.1:4173/)を開きます。

```sh
npm run check
npm test
```

GitHub Actionsの設定例は`docs/github-actions-check.yml`です。現在のGitHub連携にはworkflow権限がなく、ワークフローファイルのpushが拒否されたため、手動登録用のテンプレートとして同梱しています。GitHub上のCI実行は未設定です。

## Cloudflareへの公開

Cloudflare公式Wrangler、Cloudflareアカウント、Workers AIを使える状態が必要です。CLIを追加する場合は発行元とバージョンを確認し、利用者が承認したものを使用してください。

```sh
npx wrangler login
npx wrangler whoami
npx wrangler deploy --dry-run
npx wrangler deploy
```

`wrangler.jsonc`に静的アセット、AIバインディング、AI呼び出しのレート制限を定義しています。APIキーをフロントエンドに置きません。公開URLで`/api/health`の`aiConnected`が`true`であることを確認してください。

AIのモデルは`@cf/qwen/qwen3-30b-a3b-fp8`。Cloudflare公式モデルページで存在を確認したモデルです。利用できるモデルは変わるため、公開前に確認してください。

## 制約

- 通常の採点は意味理解を行う生成AIではなく、文章内の具体的な指示のパターンを確認するルールです。点数は成果物の品質を保証しません。
- ロールプレイはお題ごとの教材質問です。「AIコーチに相談」では自由文の助言・追加質問を受け取れます。
- 下書き・自作ワード・履歴はブラウザのlocalStorageに保存します。サーバー同期、インポート、自動バックアップはありません。
- パスワード・ユーザーDB・ログインは設けていません。Googleログインは教材の用語として収録しています。端末間同期を追加する場合に認証も設計してください。
- AIコーチはCloudflareの接続と利用枠が必要です。未接続時は503を返し、その旨を画面に表示します。
- AIは無料枠と利用制限がある外部サービスです。アカウントの請求上限はアプリのIP単位レート制限と別に管理してください。
- 音声入力はWeb Speech API対応ブラウザとマイク許可が必要です。音声がブラウザ提供元に送信される場合があります。文字入力とOS音声入力も利用できます。
- 実在の患者・顧客情報は入力しないでください。医療テーマは研修・案内・運用確認などの間接業務に限定しています。

詳しくは[技術選定](docs/技術選定.md)と[検証記録](docs/検証記録.md)を参照してください。
